- **Change a mission yourself.** With Pull Request Order on, an Azure DevOps pull request's menu, in its row, its
  details, on the Map and on the Board, has **Mission**: set it as next to merge, check or uncheck what it merges after,
  or move it to another mission, a new one of your own, or out of missions. A Copilot session's later change wins only
  where it goes against yours, and By Mission says who made it: **Put Yours Back** makes yours hold again, and **Undo**
  takes back your last change. BriefBar keeps your changes in its preferences, as references only, those about a pull
  request someone sent you in a chat in memory only, and changes nothing in Azure DevOps.
- **A stacked branch counts in a session's order too.** By Mission now puts a pull request after the one whose branch it
  targets, also when that one is in another mission, though the order a Copilot session told doesn't say so, and says
  why. Where the branches only look stacked, **Move to Mission ▸ Not in a Mission** takes it out.
