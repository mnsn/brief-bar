- **A split's line to a pull request that comes back takes it back.** When a session's order puts a pull request after
  one that had been abandoned, and that one is reactivated, the line now takes what the split moved back into the
  order's mission, even if you changed the split since, such as with **Set as Next**, **Undo** or **Put Yours Back**.
  Before, the line could stay cut, so a pull request read **Next to merge** while its order put it after an open one.
