- **A clearer look, from the start.** A new install starts with **Clearer States and Counts**, **Aligned, Easier-to-Read
  Rows** and **Simple Layout Choices** on, in **Settings › Appearance**, and the other options off. An update keeps the
  look you have: to get the same, turn those three on there. Each option now says what it does in a line, with the rest
  behind **ⓘ**, and those a new install starts with come first.
- **One menu-bar item, from the start.** A new install starts with one BriefBar item in the menu bar, which each source
  you turn on joins, with its counts added up by state and one list of everything by state. Sprint and Pipelines start
  hidden, as before, and **Give Each Its Own Item**, in **Settings › Menu Bar**, gives each section an item of its own.
  An update keeps your items: to have one, click **Put All in One Item** there (under **Custom**, with Simple Layout
  Choices on), then set its **Counts** to **Added Up** and its **List** to **Everything by State**.
