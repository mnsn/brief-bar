- **With three missions, the Board sets a pull request as next where that frees it.** Where you set a pull request as
  next to merge in one mission and two others' orders have it too, the Board works out for each of the two whether the
  first's order would hold it again. So it sets it as next in one where it wouldn't, rather than refusing there because
  it would in the other. Where it refuses, it says where the pull request waits in that lane's mission.
