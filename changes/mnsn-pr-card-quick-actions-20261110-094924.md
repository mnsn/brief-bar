## Descriptions

Azure DevOps: with Show Links, without Send Work to Copilot or once a pull request is closed, the folder the Copilot
session its details name works in, from that session's state, while they're on screen, for them to open it; kept in
memory only.

After this update: with Show Links on, Azure DevOps reads the folder the Copilot session on a pull request works in,
from its session state, while the pull request's details show, to open it there, as it does with Send Work to Copilot
on.
