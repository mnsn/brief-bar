- **A card a key moves keeps the keyboard while Copilot's work changes where it goes.** On My Work's Board, when
  Copilot stopped working on a work item while the state that **⌘→** or **⌘←** set was on its way to Azure DevOps, its
  card lost the keyboard where it went, which could be out of sight: into a column you hid, or into a story's or
  finished mission's lane that then folded. It now keeps the keyboard, even where it moves twice, once as Copilot stops
  and again as Azure DevOps answers; the column shows for the moment, and the lane stays open. And when Copilot starts
  working on it meanwhile, so that its card stays where it was, a column you hid no longer shows for it.
