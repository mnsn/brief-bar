- **A month away no longer forgets what you set and chose.** BriefBar forgets a stage you set, or a pull request you
  chose in Up Next, once no list has had its pull request for 30 days. It now counts that only once Azure DevOps has
  read your lists, as the account you're signed in with, since BriefBar started or you turned Pull Request Order on: so
  after a month away, it keeps one whose pull request never moved, rather than forget it while the Azure CLI waits for
  you to sign in again.
